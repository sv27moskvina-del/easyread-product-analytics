# Продуктовая аналитика EasyRead: приоритизация гипотез по ICE

## О проекте

Учебный проект по продуктовой аналитике на основе кейса приложения **EasyRead** — популярного сервиса для чтения книг онлайн и прослушивания аудиокниг. Команда продукта хочет улучшить ключевую метрику — **конверсию в платящих подписчиков**.

**Бизнес-контекст:** у приложения 12 млн пользователей, из них 3 млн — платящие подписчики (конверсия 25%). Продакт-менеджер сформировал 5 гипотез роста. Задача — рассчитать приоритет каждой гипотезы с помощью фреймворка **ICE** и определить оптимальную очередность внедрения.

---

## Задачи

1. Рассчитать потенциальный **Impact** каждой гипотезы в абсолютных числах (новые платящие пользователи).
2. Перевести Impact в единую шкалу 1–10 для сравнения гипотез.
3. Оценить **Confidence** (уверенность в эффекте) и **Ease** (простоту реализации) по каждой гипотезе.
4. Рассчитать **ICE-скор** и построить рейтинг гипотез.
5. Сформировать рекомендации по очередности внедрения.

|------------|----------|
| Всего пользователей | 12 000 000 |
| Платящих подписчиков | 3 000 000 |
| Неплатящих пользователей | 9 000 000 |
| Текущая конверсия | 25% |

**Упрощение:** количество новых привлечённых пользователей равно количеству ушедших (база стабильна).

## Описание гипотез

### Гипотеза 1. Рекомендации
Внедрить блок персонализированных рекомендаций для подростков (20% неплатящих). 30% из сегмента начнут конвертироваться в подписчиков.

### Гипотеза 2. Ускорение загрузки
Ускорить загрузку страниц книг для пользователей с медленным интернетом (30% базы). Конверсия увеличится на 2 п.п.

### Гипотеза 3. Тексты в email-рассылках
Персонализировать тексты в email. Конверсия увеличится на 5% относительно (для всех пользователей).

### Гипотеза 4. Пробный период с расширенным функционалом
Ввести пробный период для новых пользователей. Конверсия увеличится на 10% относительно.

### Гипотеза 5. Тариф по сниженной цене
Ввести базовый тариф для пользователей с низким бюджетом. Привлечёт 5% неплатящих.

## Расчёт Impact

| Гипотеза | Формула | Impact (новые платящие) |
|----------|---------|-------------------------|
| 1. Рекомендации | 9 000 000 × 20% × 30% | **540 000** |
| 2. Ускорение загрузки | 3 600 000 × (27% − 25%) | **72 000** |
| 3. Email-рассылки | 12 000 000 × 25% × 5% | **150 000** |
| 4. Пробный период | 12 000 000 × 25% × 10% | **300 000** |
| 5. Сниженный тариф | 9 000 000 × 5% | **450 000** |

## Приоритизация по ICE

### Методология

**ICE = Impact × Confidence × Ease**, где каждый фактор оценивается по шкале 1–10.

**Impact** переведён в шкалу 1–10 по формуле линейного масштабирования:

```
x_scaled = a + (x − x_min) × ((b − a) / (x_max − x_min))
```

где `a = 1`, `b = 10`, `x_min = 72 000`, `x_max = 540 000`.

### Оценка Confidence и Ease

| Гипотеза | Confidence | Обоснование |
|----------|------------|-------------|
| 1. Рекомендации | 4 | Фича есть у всех конкурентов, но без внутренних данных |
| 2. Ускорение загрузки | 3 | Есть запрос клиентов, но внутренних исследований нет |
| 3. Email-рассылки | 7 | A/B-тесты подтвердили рост открытий на 10% |
| 4. Пробный период | 9 | Подтверждено масштабным MVP и данными после запуска |
| 5. Сниженный тариф | 2 | Только мнение продакта и внешнего эксперта |

| Гипотеза | Ease | Обоснование |
|----------|------|-------------|
| 1. Рекомендации | 5 | 2 разработчика + 1 аналитик, 2 недели |
| 2. Ускорение загрузки | 4 | 3 недели работы backend-команды |
| 3. Email-рассылки | 9 | 3 дня работы копирайтера |
| 4. Пробный период | 7 | 1 неделя на доработку системы |
| 5. Сниженный тариф | 2 | 1 месяц работы всех команд |

## Ключевые выводы

### Победитель — Гипотеза 4: Пробный период с расширенным функционалом
- **ICE = 315** — максимальный скор
- Высокая уверенность (Confidence = 9): подтверждено MVP
- Относительно простая реализация (Ease = 7): 1 неделя работы
- Ожидаемый эффект: **+300 000 новых платящих пользователей**

### 2 место — Гипотеза 1: Рекомендации
- **ICE = 200**
- Максимальный Impact (540 000 пользователей), но средняя уверенность
- Требует больше ресурсов (3 специалиста, 2 недели)

### 3 место — Гипотеза 3: Email-рассылки
- **ICE = 126**
- Низкий Impact, но очень простая реализация (3 дня копирайтера)
- Хороший «быстрый выигрыш» при минимальных затратах

## Рекомендации по внедрению

**Очередность:** 4 → 1 → 3 → 5 → 2

1. **Первым шагом** — запустить пробный период с расширенным функционалом (наибольший ICE, подтверждённые данные).
2. **Вторым шагом** — внедрить персонализированные рекомендации для подростков (максимальный абсолютный Impact).
3. **Третьим шагом** — персонализировать email-рассылки (быстрый результат при минимальных затратах).
4. **Далее** — рассмотреть сниженный тариф (требует кросс-командной работы).
5. **В последнюю очередь** — ускорение загрузки (наименьший ICE, требует дополнительных исследований).
